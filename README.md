# Hi, I'm Q

## Computational Biologist | Multi-Omics | Machine Learning

Computational Biologist with a PhD in Bioinformatics and 8+ years of experience developing data analysis workflows, visualization tools, and machine-learning approaches for large-scale biological datasets.

My work focuses on integrating heterogeneous biological data, including genome-wide DNA methylation, RNA-seq, somatic mutation, and clinical outcome data, into reproducible analytical frameworks that support biological discovery across molecular scales.

I am particularly interested in building robust computational foundations for multi-omics and spatiotemporal biology.

## What I work on

- Multi-omics data integration and biological interpretation
- ERRBS and genome-wide DNA methylation analysis
- Bulk and single-cell RNA-seq workflows
- ChIP-seq and ATAC-seq analysis pipelines
- Machine learning and transfer learning for biological discovery
- Reproducible analysis with Python, R, Bash, Linux, and Git
- Interactive visualization tools for complex biological datasets

## Featured projects

### Research and bioinformatics

- [MDS_AZA](https://github.com/santur90/MDS_AZA) - ERRBS, RNA-seq, and multi-omics machine-learning analysis code supporting MDS/AZA research.
- [single_cell_analysis](https://github.com/santur90/single_cell_analysis) - Single-cell RNA-seq workflow covering QC, normalization, HVG selection, PCA, clustering, UMAP/t-SNE, marker discovery, and annotation support.
- [RNA_seq_analysis](https://github.com/santur90/RNA_seq_analysis) - Bulk RNA-seq workflow from trimming and alignment through feature quantification, DESeq2, and GSEA.
- [ERRBS_analysis](https://github.com/santur90/ERRBS_analysis) - Bismark-based ERRBS methylation workflow with methylSig differential methylation analysis.
- [ML_analysis](https://github.com/santur90/ML_analysis) - Leakage-safe multi-omics classification using methylation, expression, and clinical or mutation features.
- [ChIP_seq_analysis](https://github.com/santur90/ChIP_seq_analysis) - Configurable ChIP-seq workflow for alignment, filtering, peak calling, replicate assessment, and signal visualization.
- [ATAC_seq_analysis](https://github.com/santur90/ATAC_seq_analysis) - ATAC-seq workflow with mitochondrial filtering, Tn5-aware processing, peak calling, TSS enrichment, and replicate QC.
